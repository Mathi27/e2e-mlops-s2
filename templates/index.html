What happens when you press the button

1.JavaScript (fetch) sends an HTTP POST to /predict with the form as JSON.
2.Flask checks the input and rebuilds the model features (age, mileage per year, bins, encodings).
3.The saved model (best_model.pkl) predicts the price in dollars.
4.Flask answers with JSON; this page displays it.
